# Smart Review

A web-based tool that helps businesses collect Google Reviews through NFC and QR Code.

## Overview

Smart Review simplifies the customer review process by providing a direct link to a business's Google Review page.

**Flow:**

`NFC / QR Code → Google Review → Customer Review`

## Features

* Google Review link generation
* NFC & QR Code integration
* Review stand template generation
* WhatsApp review message templates
* Business dashboard

## Tech Stack

* React
* TypeScript
* Vite
* Tailwind CSS
* Firebase
* Firestore

## Technical Highlights

* Direct Google Review URL using Place ID
* Dynamic QR Code generation
* Unique ID generation with Nanoid
* Firebase Firestore integration
* Security rules and environment variables
